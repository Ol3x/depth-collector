# Research Workflow

This document defines the standard research path for new dataset candidates.

## Workflow

1. Discover a candidate dataset or HF package.
2. Create an initial note using the dataset candidate template.
3. Apply the dataset triage checklist.
4. Decide whether the dataset belongs in:
   - rejection
   - watchlist
   - `P2`
   - `P1`
   - `P0`
5. Add or update the dataset status note under `docs/datasets/`.
6. Update the inventory or prioritization documents only if the evidence justifies it.

## Why This Matters

Without a standard workflow, the roadmap will drift toward whichever datasets happen to have the most enthusiastic notes.

The project needs candidate evaluation to be:

- repeatable
- comparable across datasets
- conservative about geometry quality
- explicit about evidence and uncertainty

## Evidence Standard

When possible, each research pass should distinguish:

- official source-backed claims
- HF packaging observations
- inference

Strong roadmap changes should be based on direct evidence rather than vague reputation.
